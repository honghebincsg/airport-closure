# 全球机场 NOTAM（航行通告）公开源调研与实测

实测时间：2026-11-19 22:55 CST（数据快照 14:58Z）
测试机场：KJFK / KLAX / KORD / PANC 及 10 个境外机场

## 一、结论先说

1. **有公开源，而且不用申请密钥就能跑**：FAA NOTAM Search 的查询接口（POST `/notamSearch/search`）实测可用，一次能拿某个机场全部有效通告，**还能返回境外机场**（广州、北京、香港、伦敦、法兰克福、悉尼、迪拜等实测都有数据）。
2. **要"权威 + 全量 + 可分析"**，走 FAA 官方 API（`external-api.faa.gov/notamapi/v1`，免费注册）+ FAA NMS（提供全量压缩包和增量），这两个才是给程序用的正式通道。
3. **中国机场的 NOTAM 没有公开源**，FAA 库里能看到的中国通告是国际转发副本，不代表完整、也不保证时效。
4. 任何公开网页版 NOTAM 都是"信息性"用途，**不能作为放行/运行决策的唯一依据**。

## 二、实测可用接口（重点）

基础地址：`https://notams.aim.faa.gov/notamSearch/`
查询接口：`POST https://notams.aim.faa.gov/notamSearch/search`

请求体（form-urlencoded）：

```
searchType=0&designatorsForLocation=KJFK&offset=0&limit=30
```

- `designatorsForLocation`：ICAO 四字码，支持单个；`searchType=0` 为按地点检索
- `offset` / `limit`：**实测有效**，offset=30&limit=30 时返回第 31–60 条（默认只给 30 条）
- 返回字段：
  - `notamList[]`：每条含 `notamNumber`、`featureName`、`source`、`issueDate`、`startDate`、`endDate`、`icaoMessage`（完整 ICAO 报文，含 Q/A/B/C/D/E 段）
  - `totalNotamCount`：该机场通告总数
  - `startRecordCount` / `endRecordCount`：当前页区间
  - `countsByType`：RNAV、Ending this month、LTA、TFR 等分类计数
  - `searchDateTime` / `criteriaCaption`：快照时间与查询条件

**踩坑**：从云主机用 `curl` 访问该域名会被代理拦成 `502 after CONNECT`，但浏览器内 `fetch` 正常。也就是说抓取脚本要么走正常出口 IP，要么放在能访问该域的机器/Worker 上跑。

| Q 码 | 条数 | 含义 | 典型样例 |
| --- | --- | --- | --- |
| QMMXX | 62 | 机坪/滑行道标识与标志 | `TWY J SFC PAINTED HLDG PSN SIGNS FOR RWY 04R/22L FADED` |
| QXXAS | 34 | 其他（灯光类本地通告） | `TWY H CL LGT BTN TWY Y AND TWY Z NOT STD` |
| QOBXX | 20 | 障碍物 | `CRANE (ASN 2025-AEA-4297-NRA) 403811N0734703W (0.3NM SW JFK) 112FT (100FT AGL)` |
| QPIXX | 9 | 飞行程序（ILS/RNAV） | `ILS OR LOC RWY 22R, AMDT 4... S-LOC 22R MDA 580/HAT 567` |
| QMXLC | 7 | 滑行道关闭 | `TWY TB BTN TERMINAL 8 RAMP AND TWY A CLSD` |

分析结论：JFK 当前通告主体是**机坪与滑行道标志/灯光维护（占 57%）**，跑道类硬关闭极少，程序类只有 ILS 附近 9 条，障碍物 20 条（多为 crane）。这类结构非常适合做"运行影响面"打分：滑行道/机坪类影响地面滑行，灯类影响低能见运行，程序类影响进近最低标准。

## 五、其他公开源（分级）

### A. 免密、可直接抓（已验证）
- **FAA NOTAM Search** `notams.aim.faa.gov/notamSearch` —— 就是上面这套，美国 + 国际都有，有分页，无密钥。

### B. 免费但要注册（正式通道）
- **FAA NOTAM API** `https://external-api.faa.gov/notamapi/v1/notams?icaoLocation=KJFK`
  - 实测：接口在线，未带密钥返回 `{"message":"Unauthorized","http_status_code":401}`
  - 需在 `api.faa.gov` 申请 `client_id` / `client_secret`，请求头带这两个值。免费，适合生产
- **FAA NMS（NOTAM Management Service）** `https://nms.aim.faa.gov`
  - 提供 **initial load**（全 NAS 有效通告压缩包一次性拉取）+ 增量，适合做全量库
  - 需在 NMS 门户提交 API access request（onboarding），页面显示已接入用户 261 个
- **FNS WFS（数字 NOTAM）** `notams.aim.faa.gov/notamWFS`
  - 按 OGC WFS 2.0 + AIXM 5.1 下发，是**结构化数字通告**，做机器分析最省事
  - 需注册账号，目前是 demo 状态

### C. 可访问但非接口
- **DINS 旧版** `www.notams.faa.gov/dinsQueryWeb` —— 表单式，可 GET 参数化查询，本机被代理拦截，公网一般可用

### D. 其他区域
- 欧洲：**EUROCONTROL EAD**（付费订阅，最权威的欧洲 NOTAM/AIP 库）；NATS AIS（英国，付费）；DFS（德国）、ENAV **AISWEB**（意大利，部分免费）
- 澳洲：**Airservices NAIPS**（需账号）
- 亚洲：日本、韩国、新加坡有各自 AIS 门户，多为注册制
- **中国：无公开 NOTAM 源**。CAAC / 空管局（ATMB）内部发布，对外只有 AIP 和商业数据商
- 商业聚合（全球一套接口）：Jeppesen、Lufthansa Lido、Opsgroup、Notamify 等，按量付费

## 六、给抓取程序的建议

1. **主通道**用 FAA NOTAM API（注册密钥），**兜底**用 NOTAM Search 免密接口，两者字段可对齐到 `notamNumber + icaoLocation`。
2. **去重主键**：`icaoLocation + notamNumber + issueDate`；同一编号会有 `NOTAMN` / `NOTAMR`（替换）/ `NOTAMC`（取消）三种状态，必须按**替换链**处理，否则会重复计数。
3. **必存生命周期四段**：Q 码（分类）、B 生效、C 失效、D 时间表（如 `22 SEP-23 OCT 2130-0330`）。D 段是"每天几点关"的关键，分析跑道夜间关闭必须解析它。
4. **落库表结构建议**：机场、Q码大类/子类、E 段文本、经纬度半径（Q 行末 `4038N07346W005` 里的 005 是半径 NM）、状态。
5. **优先级打分**：跑道关闭（QMR**）> 滑行道关闭（QMX**）> 进近灯光（QLT**）> 程序（QPI/QPL**）> 机坪标志（QMM**）> 障碍物（QOB**）。
6. **抓取频率**：美国每 5–15 分钟增量足够；国际通告延迟更大，30–60 分钟即可。

## 七、风险与合规

- NOTAM Search 页面自述："informational in nature… not to be considered as a sole source"，只能做**辅助分析**，不能替代放行资料。
- 国际通告在 FAA 库里是**转发副本**，条数与本国 AIS 不一致（如仁川 RKSI 只有 3 条，明显偏少），做全球分析时不能用它衡量"某国通告多少"，只能用来看"有没有这条"。
- 抓取请控制频率，加 UA 与缓存，避免被判为异常流量。
